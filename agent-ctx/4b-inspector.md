# Task 4b — Inspector (properties panel)

## What I built
- `/home/z/my-project/src/components/editor/inspector.tsx`
- Default export `Inspector`, a `'use client'` React component, no props.
- Reads all state from `useEditorStore` (src/lib/editor/store.ts) + `useSelectedStructure` hook. Did NOT modify the store.

## Store API consumed
- State: `selectedEntityIds`, `settlement`, `edits`.
- Derived: `useSelectedStructure()` → effective (edits-merged) structure for the single selection.
- Actions: `applyEdits` (used with single-element arrays so a transaction is recorded per commit), `resetEdits`, `clearSelection`.

## Layout
Dark wrapper (`className="dark"`, `bg-zinc-950 text-zinc-300`, `border-l border-zinc-800/80`), three regions:

1. **Header** (fixed, `h-9`) — `INSPECTER` label (uppercase tracking-wider `text-[11px] text-zinc-500`). Right side: kind badge (icon + label, accent-colored per kind) + `#entityId` emerald mono badge. In multi-select mode shows an amber `N sel` badge instead.

2. **Body** (scrollable, `flex-1 overflow-y-auto`, thin custom webkit scrollbar `[&::-webkit-scrollbar]:w-1.5 [&::-webkit-scrollbar-thumb]:bg-zinc-700`):
   - **Empty state** (`selectedEntityIds.length === 0`): centered `MousePointer2` in a zinc disc, "Nothing selected", helper text in `text-zinc-600`.
   - **Multi-select** (`length > 1`): centered `Layers` icon, "N entities selected", "Clear Selection" button.
   - **Single select** + structure found: shadcn `Accordion` (`type="multiple"`, `defaultValue` = all applicable sections open). Sections rendered via a reusable `Section` component (wraps `AccordionItem` + `AccordionTrigger` + `AccordionContent` together — Radix requires content inside item):
     1. **TRANSFORM** (5 rows): `NumberField` for Position X, Position Z, Rotation (deg), Width, Depth. Each row: icon + uppercase label left, mono numeric Input right with unit suffix. Rotation converts radians↔degrees. Width/Depth clamped to min 0.1.
     2. **IDENTITY** (4 rows): Name, Hanzi (名), Kind (icon+label), Entity ID (#N) — definition-list style via `DefRow`.
     3. **HOUSEHOLD** (only if `kind === 'household'`): head summary card (name + hanzi + role + Wang badge + wealth-tier badge), 2-col grid of Age/Members/Paddy/Tenanted/Dryland/Has Well/Pigs/Chickens, wealth-tier color legend. Wealth tiers colored: rich=emerald, comfortable=cyan, poor=amber, destitute=rose.
     4. **METADATA**: every key:value pair from `structure.metadata`. Primitives as inline values (numbers emerald, booleans as tiny badges, strings plain); arrays/objects as collapsed JSON in `<pre className="font-mono text-[10px]">` with own max-h-40 scroll. `max-h-96 overflow-y-auto` on the whole list.
     5. **PROVENANCE**: Generated by (`ga:gen-settlement`), Seed, Tick (settlement.tick), Permission (`presentation_only` amber badge).

3. **Footer** (fixed): rose-tinted "Revert Edits" button (`Undo2` icon) calling `resetEdits()`, disabled unless `edits[entityId]` has entries. Tooltip explains edit count. Right side: live "N edited" indicator (amber pulse dot) or "clean" when no edits.

## NumberField sub-component
Props: `{ label, value, onCommit, step?, min?, max?, unit?, icon?, degrees? }`.
- Local string `draft` state synced from prop via `useEffect` (only when not focused).
- `onCommit` fires ONLY on blur or Enter (Escape reverts draft to prop value). Parses with `Number()`, rejects non-finite/empty, clamps to min/max.
- `degrees` mode: displays `value * 180/π`, commits back as `deg * π/180` (rotation field).
- Input styled: `h-6 w-20 text-xs font-mono bg-zinc-900 border-zinc-800 text-right tabular-nums`, emerald focus ring.

## Household lookup
`findHousehold(structure, settlement)`:
1. Prefer `metadata.householdIndex` → index into `settlement.households`.
2. Fall back to matching `metadata.headName` against `settlement.households[].headName`.
3. Final fallback: synthesise a `SerializableHousehold` from the metadata fields (the generator spreads the full household record into metadata, so this is always populated for households). Uses typeof-narrowing helpers (`readMetaNumber/String/Boolean`) — no `any`.
