## Document-level vs claim-level annotation problem

The retrofit added ONE truth-level header per document. But a single document can contain
claims of different truth levels. For example, a combat document may contain:

  [CANON] Cultivators can perceive spiritual energy.
  [DERIVED] This requires an engine perception channel.
  [ART] Spiritual perception uses restrained color separation.
  [PROC] Regional presentation varies with local laws.
  [UNRESOLVED] Whether mortals can perceive residual traces.

Adding one header to the document does NOT classify the claims inside it.
The correct approach is claim-level ground-truth records (see redesign below).

## Required redesign: claim-level ground-truth records

Every significant claim must have:

```json
{
  "claimId": "stable-unique-id",
  "truthLevel": "CANON | DERIVED | ART | PROC | UNRESOLVED",
  "statement": "exact claim text",
  "source": "doc-NN §X.Y or user-decision-YYYY-MM-DD",
  "provenance": "user-approved | logically-derived | art-directed | procedural | unresolved",
  "confidence": "exact | derived | art-directed | estimated",
  "dependencies": ["other-claim-id", ...],
  "applicableSystems": ["cultivation", "combat", ...],
  "contradictions": [],
  "approvalStatus": "approved | candidate | rejected | blocked"
}
```
